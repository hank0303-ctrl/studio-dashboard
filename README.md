# studio-dashboard

## 手機同步設定

這套系統現在支援「電腦輸入、手機同步查看」。資料仍會先存在目前裝置的瀏覽器，並可同步到 Google 試算表，讓電腦和手機讀同一份資料。

### 建立 Google 試算表同步後端

1. 到 Google Drive 新增一份試算表，例如命名為「武樂教室管理系統資料」。
2. 在試算表選單點「擴充功能」→「Apps Script」。
3. 將本專案的 `apps-script.gs` 內容貼到 Apps Script 編輯器並儲存。
4. 如需同步密碼，進入 Apps Script「專案設定」→「指令碼屬性」，新增：
   - 屬性：`SYNC_TOKEN`
   - 值：自行設定一組密碼
5. 點「部署」→「新增部署作業」→ 類型選「網頁應用程式」。
6. 執行身分選「我」，存取權選「任何知道連結的人」。
7. 部署後複製 Web App 網址。

### 在系統內啟用同步

1. 打開教室管理系統。
2. 點右上角「設定」。
3. 貼上 Apps Script Web App 網址。
4. 輸入同步密碼，電腦和手機要填同一組。
5. 電腦輸入資料後會自動推到雲端；手機點「同步」即可讀取最新資料。

### 同步 Gmail 購買方案信件

1. 先依上方步驟部署 `apps-script.gs`。
2. 如果之前已部署過 Apps Script，請重新部署一次「新版」Web App，因為這次新增了 Gmail 權限。
3. 第一次執行時，Google 會要求授權讀取 Gmail。
4. 到系統「學員方案」頁，點「📩 同步信箱購買」。
5. 預設搜尋近 90 天含「購買成功通知、bookfastpos、servicealarm.mirle、武樂武術、每日營收、武樂營隊新報名」等購買相關信件。
6. 系統會自動略過重複信件，新增到「本月購買明細」與「學員方案」列表。
7. 同步時也會掃描既有試算表內的購買資料欄位，例如「會員姓名、商品名稱、訂購時間、付款內容、使用期限」。
8. 同步完成後會顯示找到幾封信、試算表解析幾筆、新增幾筆，方便確認資料來源。

### 使用建議

- 電腦作為主要輸入裝置。
- 手機主要用來查看數據，避免小螢幕誤觸。
- 如果手機看不到最新資料，先在電腦點「同步」，再到手機點「同步」。
- 如果 Gmail 信件格式有改，先調整搜尋條件；若仍抓不到，需依信件內容補解析規則。
